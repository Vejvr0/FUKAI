# FUKAI

Toto je <i>Fakultná Univerzálna Kognitívna AI</i> [<b>FUKAI</b>] desktop aplikácia, ktorá ti pomôže pri každodenných dotazoch, práci so súbormi, s domácimi úlohami a rôznymi inými problémami lokálne u teba na počítači.

## About

Aplikácia je crossplatform pre <b>Windows</b> a <b>MAC OS</b>. Samotná aplikácia je programovaná v jazyku <b>Python</b>, ktorá je schopná rozbehnúť rôzne LM modely na základe knižnice <b>llama-cpp-python</b>. Vhodný LM model pre používanie závisí od samotnej hardware-ovej konfigurácie užívateľského zariadenia. Projekt je dostupný zadarmo bez potrebej licencie <i>(vývojové štádium)</i>.
